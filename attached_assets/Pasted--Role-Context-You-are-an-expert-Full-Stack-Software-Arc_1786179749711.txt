# Core Feature Modules to Implement (The Complete MVP)

## Module 1: The Blueprint Compliance & Audit Engine
* **Architect Portal:** A clean submission form where architects upload building blueprints (PDF/CAD mock upload) and input structural specs (e.g., ramp slope, door width, lift availability).
* **Automated AI Checker:** A rule-engine simulator that cross-references inputs against accessibility laws (RPwD Act / National Building Code standards) and instantly generates a structured **AI Compliance Gap Report** highlighting missing items (Critical, Moderate, Minor).
* **Auditor Portal:** A parallel section where independent third-party auditors upload their field inspection reports.
* **Public Transparency Ledger:** A side-by-side comparison view displaying the **Builder Name, Auditor Name, AI-Generated Report, and Auditor Field Report** transparently to the public, preventing paper-only compliance.

## Module 2: The Star-Rating System & Public Dashboard
* **Dynamic Rating Engine:** Every registered building receives an automated **1 to 5 Star Accessibility Rating** calculated dynamically based on resolved vs. unresolved critical gaps.
* **Search & Filter Directory:** A clean public directory where citizens can search buildings, view their 5-star ratings, and check live audit statuses (Red/Amber/Green).

## Module 3: Universal Web Accessibility & Inbuilt Screen Reader
* **WCAG Compliance:** Fully semantic HTML architecture (`<nav>`, `<main>`, `<article>`, `<button>`), visible keyboard focus indicators (`focus:ring-2`), and high-contrast color ratios.
* **Inbuilt Screen Reader Toolbar:** A floating or fixed accessibility widget on the website featuring a **"Read Aloud"** toggle button. When clicked, it uses the browser's speech synthesis engine to read selected text blocks, audit reports, or navigation instructions out loud natively inside the app.
* **Visual Toggles:** Built-in toggles for **High Contrast Mode** and **Color Inversion** that instantly transform the DOM styling without breaking layout components.

## Module 4: The Dual-Mode Live Building Map
* **Mode 1: Normal Map Mode:** An interactive indoor floor plan map (powered by Leaflet.js) showing real-time pins for elevators, ramps, and restrooms with live color status. Clicking a pin opens its audit history and star rating.
* **Mode 2: Video Navigation Mode (Simulated Assistive AR View):** A live camera feed interface (`navigator.mediaDevices.getUserMedia`) rendered inside the app. Overlay text and real-time audio announcements simulate spatial guidance (e.g., *"Proceed 5 meters straight: Accessible ramp ahead to your left"*), utilizing browser speech synthesis to narrate detected checkpoints dynamically.
